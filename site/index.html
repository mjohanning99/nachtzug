Nachtzug

Sequencer · Synthesiser

A little music machine for acid and Berlin School music. Every note is in the song’s scale, so you can make music without being able to play the keyboard.

Einsteigen, bitte! Download Nachtzug, it’s free The manual English · Deutsch · PDF

For Linux, macOS and WindowsNZ · 001

NNNachtzug is a small music program for the kind of music that’s built from repeating synthesiser patterns: squelchy acid basslines, rolling Berlin School sequences, slow pads and simple melodies on top, all carried along by a drummer who never gets tired.

You don’t need to be able to play an instrument, and you don’t need to know any music theory. Nachtzug only lets you place notes that fit the song, it comes up with ideas when you’re stuck, and every change you make while the music plays waits politely for the next bar, so it always lands in time.

And don’t worry about breaking anything! Every change can be undone, and Nachtzug quietly keeps a spare copy of your song in case something goes wrong.

Bordbuch · The manual

An operation manual, as it should be

Operation manual English · PDF Bedienungsanleitung Deutsch · PDF

NNNachtzug comes with a proper printed manual, the way old synthesisers did: an A5 booklet with pictures of every part, sound recipes, patch sheets to fill in, a table of every key and an index. Read it front to back, or just the chapter you need. It’s in English and in German.

Inside the program, F1 opens a short guide, Help → Lessons has five guided tours, and almost every button and knob explains itself when you rest the mouse on it.

Building Nachtzug yourself

Don’t let that put you off: it’s a handful of commands, and you only have to do it once.

On Linux

Install the tools. On Arch:

sudo pacman -S --needed base-devel cmake qt6-base qt6-tools sdl2 alsa-lib git

On Debian or Ubuntu:

sudo apt install build-essential cmake qt6-base-dev qt6-tools-dev qt6-l10n-tools libsdl2-dev libasound2-dev git

Then unpack the source code (the last ticket above) and run these two in its folder:

cmake -B build
cmake --build build -j

./build/nachtzug starts it.

On a Mac

Install Apple’s command line tools (xcode-select --install) and Homebrew, then unpack the source code and run this in its folder:

tools/build-macos.sh

It installs everything else, builds the app and packs it into a disk image.

On Windows

Install MSYS2, open the MSYS2 UCRT64 terminal from the Start menu, then unpack the source code and run this in its folder:

tools/build-windows.sh

It installs the compiler and everything else, builds Nachtzug and makes an installer (with Inno Setup installed) or a zip.
